## 🚀 Projects

| # | Project | Description | Key Concepts |
|---|---------|-------------|--------------|
| 1 | 📝 **Registration Form** | Full student registration form with every input type including file upload, range slider, checkboxes, dropdowns | `<form>`, all input types, `<select>`, `<textarea>`, validation |

## 🧠 What I Learned

This portfolio covers everything from the Apna College HTML course:

- **Structure** — DOCTYPE, head, body, meta tags
- **Text** — headings, paragraphs, strong, em, span
- **Links & Navigation** — anchor tags, in-page navigation with `id`
- **Media** — images with `src` and `alt`, iframe
- **Lists** — ordered, unordered, nested lists
- **Tables** — full table structure with headers, body, footer, colspan
- **Forms** — every input type: text, email, password, number, date, tel, radio, checkbox, file, range, color, submit, reset
- **Semantic HTML** — `<nav>`, `<header>`, `<section>`, `<article>`, `<footer>`, `<main>`
- **Styling** — internal CSS, class & id selectors, flexbox layout
